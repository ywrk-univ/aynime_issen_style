# 一閃 改 — 未実装機能リスト

本家 (Python版) にあって一閃 改 (Rust版) に未実装の機能。

## 優先度高
- [ ] グローバルホットキー (Ctrl+Alt+I: 一閃, Ctrl+Alt+K: キンキン)
- [ ] アニメ名オーバーレイ (キャプチャ画像にアニメ名テキストを焼き込み)

## 優先度中
- [ ] リサイズ/クロップ (キャプチャ後のサイズ変更・切り抜き)
- [ ] 転生 (プラットフォーム別エクスポート)
  - Discord 絵文字 (128x128 PNG)
  - Discord スタンプ (320x320 APNG/GIF)
  - X/Twitter 向け (JPG/MP4, サイズ制限対応)
  - '00s 風 (JPG/GIF, 低解像度)
- [ ] ドラッグ&ドロップ (保存済みファイルの読み込み・再編集)

## 優先度低
- [ ] メタデータ埋め込み (XMP/PNG text chunk に処理パラメータ保存)
- [ ] SSIM 重複フレーム検出 (動画キャプチャの自動重複排除)
- [ ] 動画再生モード (FORWARD/BACKWARD/REFLECT)
- [ ] サムネイルバー (動画フレーム選択UI)
- [ ] gifsicle 連携 (GIF 最適化)
- [ ] AVIF 出力 (静止画・動画)
- [ ] スプラッシュスクリーン
- [ ] 多重起動防止 (システムミューテックス)
